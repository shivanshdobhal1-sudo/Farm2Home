# Farm2Home Architecture

## MVP

Farm2Home is currently a client-side prototype. The browser contains the presentation layer, demo data, marketplace logic, cart logic, order logic and schematic GIS layer.

## Production direction

The MVP can evolve into a Progressive Web App/mobile application backed by an API and PostgreSQL/PostGIS database. GIS services can provide location visualization, while payment and logistics services can be integrated through secure APIs.

## Key design principle

**Technology should reduce the distance between a remote farmer and the consumer.**
