# Farm2Home 🌱

**From Real Farms to Your Home**

Farm2Home is a working MVP concept for connecting farmers in **remote and market-underserved areas** directly with consumers through a digital marketplace and GIS-style farm mapping.

## Problem

Farmers in remote areas may have limited access to nearby mandis and urban markets. Distance, transportation costs, dependence on intermediaries and limited market information can reduce price realization.

## Solution

Farm2Home provides a simple digital journey:

**Farmer → Product Listing → Farm/Village Mapping → Consumer Discovery → Cart → Demo Order**

The prototype demonstrates:

- Farmer/product publishing
- Product search and category filters
- Farmer and village information
- GIS-style village/farm discovery interface
- Direct product-to-consumer marketplace flow
- Cart management
- Demo checkout and order history
- Responsive mobile-friendly interface

## Technology

- HTML5
- CSS3
- Vanilla JavaScript
- Inline SVG for the prototype map
- No external framework or backend required

## Run locally

1. Download/clone this repository.
2. Open `index.html` in a modern web browser.
3. No installation or server is required for the current MVP.

## Prototype limitations

This is an MVP demonstration. It does not currently include real user authentication, a production database, live GPS, payment gateway, logistics integration or real-time inventory synchronization.
